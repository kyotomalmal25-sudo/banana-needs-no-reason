# Does a Banana Need a Reason?

## Site Concept

理由を求められたチンパンジーが、バナナの前で沈黙するための小さな展示サイト。

全体はラムス風の工業デザイン資料、安藤忠雄的な静かな展示空間、古い図録ポスターの余白を混ぜる。写真ではなく、半透明の羊皮紙に描いたようなチンパンジーとバナナの線画を使う。

## Structure

### 1. Top Page

Title: `Does a Banana Need a Reason?`

Role:
- サイト全体の入口
- 展示室に3枚のポスターが置かれているような構成
- テーマ、操作ボタン、基本仕様を見せる

Content:
- 大きな英語タイトル
- 日本語副題: `バナナを食べるのに理由がいるのか。`
- 中央に半透明羊皮紙のチンパンジースケッチ
- 黒点と赤橙の一点
- 物理ボタン風リンク

Links:
- `Profile / Operating States`
- `Banana Protocol`

### 2. Profile / Operating States

Role:
- 自己紹介ページ
- 人格ではなく、チンパンジーの動作状態でプロフィールを表現する

Content:
- `観察`
- `接近`
- `把持`
- `皮むき`
- `摂取`
- `沈黙`

Visual:
- 犬の線画参考のように、少ない線で動作を描く
- 顔は目・鼻・口の最小部品だけ
- かわいくしすぎない
- 図録の小さな挿絵として扱う

### 3. Banana Protocol

Role:
- バナナの剥き方を、過剰に真面目な手順書として紹介するページ

Content:
- `01 観察`
- `02 茎部確認`
- `03 把持`
- `04 皮むき`
- `05 摂取`
- `06 沈黙`

Gimmick:
- 物理ボタンを押すと手順が切り替わる
- 黒点が順に点灯する
- バナナだけ淡い黄/赤橙で反応する

### 4. Banana Phone / Product Prototype

Role:
- 発売予定・開発中製品としてのバナナ資料
- バナナを「食べ物」ではなく、通信端末・応答拒否装置・理由要求処理機として扱う

Product Names:
- `Banana Phone BO-01`
- `PeelDial 01`
- `Reasonless Contact Unit`
- `Model BP-08`

Concept:
- バナナ摂取中に理由を問われた場合、応答を保留し、沈黙を転送するための通信端末。
- 理由はいらない。ただし電話は必要。
- バナナに関しては一歩も引かない姿勢を示すため、製品仕様として過剰に真面目に扱う。

Interface:
- 数字キーをバナナ本体に配置する
- `1`: 観察
- `2`: 把持
- `3`: 皮むき
- `0`: 沈黙
- `#`: 理由の提出を拒否
- `*`: バナナに戻る

Visual:
- 写真や工作感ではなく、ラムス風の製品仕様書として描く
- 黒線、紙色、バナナ黄色を基本とする
- バナナ本体は唯一許された色面として扱う
- 電話UIは滑稽だが、見せ方は本気で先端的にする

## Visual Rules

- 写真は使わない
- AIっぽい流体、グラデーション、汎用エージェンシー風は避ける
- 色は紙色、黒、薄いグレー、赤橙一点
- 大きな余白を残すが、薄い補助線と番号カードで少し密度を上げる
- 動きは派手にしない
- 光、影、紙、点、ボタンの微細な変化を中心にする
- バナナの内容は今後も拡張する
- バナナに関しては一歩も引かない
- 見た目と技術は本気、内容は滑稽にする

## Key Phrase

`Does a Banana Need a Reason?`

日本語の核:

`バナナを食べるのに理由がいるのか。`

補助コピー:

`理由はいらない。ただし手順はある。`
